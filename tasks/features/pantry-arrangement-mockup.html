Design Mockup · Pantry Arrangement

Make the pantry feel arranged, not listed

Today every category renders as the same flat white list — a "Staples" section looks identical to "Dairy," which looks identical to "Packaged." Real pantries have zones — a shelf, a fridge door, a fruit bowl — each with its own feel. Two directions below, both keeping the existing tap-to-edit interaction so this stays a UI change, not a rebuild of the editing flow.

1Before — one flat list, five times

Every category container is the same white rounded card, same row style, same gray uppercase label. Nothing tells you Dairy from Packaged except the text.

Each category is a physical shelf — a warm, zone-tinted strip with its own shelf-lip shadow. Items sit on it as jars, horizontally arranged like you'd actually see them, fill level rising from the base like real contents. Swipe a shelf sideways to see everything on it.

3Direction B — Zone Grid

Less illustrative, more "kitchen inventory app": each category is a soft-tinted zone block, items sit in a 3-column grid as tiles with a radial fill gauge instead of a bar — reads more like a gauge cluster than a scrollbar. Lower engineering risk than jars (no custom shapes), still clearly not a plain list.

4Large categories — capped grid + "N more"

A zone caps at a clean 2-row grid (6 tiles). Items already sort depleted → low → stocked, so the 6 visible slots are always the most urgent ones — nothing that needs attention is ever hidden behind a tap. If there are more, the last slot becomes a +N more tile — same pattern already used for order previews and onboarding's go-to items elsewhere in the app. Tap it to expand the zone in place, same accordion behavior as the Nutrition card's Micronutrients reveal.

5Tradeoffs

🌾 Shelf & Jar

  • Most literal "arranged pantry" feeling — closest to the actual request
  • Horizontal scroll per shelf could hide items off-screen without a scroll hint
  • Needs a per-category color/tone mapping (wood, fridge, crate…) — more design tokens to maintain
  • Jar shape is custom CSS, not a huge lift, but more surface area than a gauge

⬡ Zone Grid

  • Everything visible at once, no horizontal scroll, easier to scan a full category
  • Radial gauge is a simple conic-gradient — least custom-shape work
  • Reads a bit more "app dashboard" than "physical pantry" — less literal to the ask
  • Needs an emoji/icon per item — either a small mapping table or a generic category icon fallback

Both keep category grouping, status-driven color, and the exact same tap-to-expand inline editor already built — only the "what does a shelf/item look like" visual changes.
