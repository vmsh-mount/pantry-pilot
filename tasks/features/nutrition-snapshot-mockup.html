Fix the framing, then the look

Today's bars compare one order's totals against a full week's household target — every bar reads as nearly empty, regardless of how good the order actually was. Below: the current card recreated exactly, then a redesign that drops the false "progress toward a target" framing in favor of composition — what this order is actually made of — plus the app's real colors instead of generic Tailwind gray.

3What this fixes
Reframes: the card stops implying "you're behind on your weekly goal from one order" (never true, always confusing) and instead answers "what did this order actually contain" (always a coherent question).
  • Macro composition bar — protein/carbs/fat as % of this order's calories (kcal from each macro ÷ total kcal), computed entirely from the order's own totals — no external target needed, so it can never show a nonsensically tiny fill.
  • Fiber & Sodium — plain stat tiles, not bars. Neither has a natural "share of this order's calories" reading, and comparing them to a weekly ceiling has the same wrong-denominator problem the old card had. Absolute numbers are honest here.
  • Confidence dots replace the boxy badges — same 4-state system (verified/database/estimate/unresolved), far less visual weight competing with the item name. A single compact legend row sits once above the item list (not repeated per row) so the dot colors are never unexplained.
  • Colors — calorie number and structure now match the rest of the app's real palette instead of arbitrary blue/mustard/purple with no relationship to anything else in PantryPilot.
  • No change to the loading/error/polling states, the underlying OrderNutrition data, or the ConfidenceBadge/MacroBar exports used correctly elsewhere (nutrition/weekly keeps using real weekly-vs-weekly MacroBar — that usage isn't touched).
