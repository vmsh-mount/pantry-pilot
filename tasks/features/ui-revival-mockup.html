Design Mockup · Scope: Shared Shell + Bottom Nav

Reviving the PantryPilot UI

Today two layout patterns fight each other: a polished green-hero + gray-body pattern (Dashboard, Pantry) and an older full-green floating-card shell (Orders, Settings, Routines, Flow…). This mockup shows the redesigned 5-tab bottom nav with standard line icons, and renders the same screen in the candidate layouts so you can pick the direction.

1Bottom navigation — 5 tabs, standard icons

Keeping all 5 tabs (incl. Settings) as you asked. The only change is replacing the emoji with a consistent stroke-based line-icon set tuned to the theme, plus a clearer active state.
